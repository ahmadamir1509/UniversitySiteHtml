# University Site HTML

A static HTML website for a university, featuring responsive design and modern web standards.

## 📋 Overview

This project is a front-end implementation of a university website using HTML, CSS, and JavaScript. It provides an informative and user-friendly interface for students, faculty, and visitors to learn about the university's programs, facilities, and services.

## 🎯 Features

- **Responsive Design** - Mobile-friendly layout that works on all devices
- **Modern UI** - Clean and professional user interface
- **Easy Navigation** - Intuitive menu structure for seamless browsing
- **Static Content** - Fast-loading HTML pages
- **Semantic HTML** - Proper HTML5 markup for accessibility

## 📁 Project Structure

UniversitySiteHtml/ ├── index.html # Homepage ├── css/ # Stylesheets ├── js/ # JavaScript files ├── images/ # Image assets └── pages/ # Additional pages (about, programs, contact, etc.)
